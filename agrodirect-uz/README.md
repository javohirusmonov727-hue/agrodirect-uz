# AgroDirect Uz
### Digital Agricultural Marketplace Prototype

AgroDirect Uz is a marketplace concept designed to connect farmers and buyers through a transparent digital platform.

## Project Overview
The platform demonstrates how agricultural sellers can list products and how buyers can discover products, compare prices, review seller information and submit order requests.

## Key Features
- Product catalog with sample agricultural products
- Search and category filtering
- Seller verification interface
- Product submission form
- Buyer order request form
- Admin approval queue
- Product and order statistics
- Responsive layout for desktop and mobile

## Technology
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Current Project Status
This repository contains a frontend prototype with sample data.
It does not yet include a production backend, authentication system, database or live API integration.

## Run Locally
1. Clone this repository.
2. Open `index.html` in a web browser.
3. Explore the product catalog, filters, forms and admin interface.

## Project Goal
To explore how digital tools can improve transparency and connections between agricultural producers and buyers.
